## Estrutura dos Arquivos

- `bloco.js`: Define a classe `Bloco`, com validações de entrada e cálculo do hash SHA-256.
- `blockchain.js`: Define a classe `Blockchain`, iniciada com o bloco gênese, com métodos `adicionar(dados)` e `ehValida()`.
- `principal.js`: Executa o fluxo completo de cadastro de entregas, testes de validação e simulação de adulteração.
